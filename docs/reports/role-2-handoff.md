## Stores / data layer
- **Dexie** (`src/lib/db.ts`): `snapshots` (url→validated payload, fetchedAt/expiresAt), `logbook`, `settings`, `seen` (what-changed baselines).
- **TanStack Query** over `fetchSnapshot()` (`src/lib/snapshots.ts`): offlineFirst networkMode, infinite gcTime, stale-while-revalidate semantics; never throws the offline path away — falls back to Dexie, reports `live:false`.
- **FreshnessChip** on every data surface: `Live · Xm ago` / `Offline · last known H:MM` (device-offline forces the offline variant).
- Pure logic all client-side from `@trout/contracts`: `matchHatch()`, `scoreConditions()`; units conversion in `src/lib/units.ts`.
