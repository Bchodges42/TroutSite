# SOURCES LEDGER — WAVE 3: TENNESSEE CREEKS (57 waters)

Merged 2026-09-15. Reference/access date for every citation: **2026-09-14**.

Method: 13 research subagents (paired batches) researched 4–6 waters each under `wave3-notes/SPEC.md` rules (agency/academic fact sources only, every URL fetched live, identity-before-citation); 2 gauge-probe subagents re-verified all 125 surfaced USGS stations against waterdata.usgs.gov + waterservices.usgs.gov; 2 QC subagents re-fetched a deterministic 1-in-3 sample of cited URLs (98 URLs, 98 loaded, 0 fabricated) and audited completeness + non-agency citations. Corrections found by QC/gauge passes were applied to the blocks below (marked inline `[QC ...]` / `[gauge-probe correction]`; full log in `wave3-notes/apply-fixes.py`).

Class taxonomy: `wild-self-sustaining` (survey/list-documented wild population) · `mixed` (documented stocking + wild component, or trout + significant warmwater fishery) · `stocked-winter` (put-and-take stocking is the documented fishery; label covers TWRA Winter AND Seasonal/Spring programs — the block text says which) · `warmwater` (sourced no-trout finding) · `none-found` (no documented fishery; attempts logged).
