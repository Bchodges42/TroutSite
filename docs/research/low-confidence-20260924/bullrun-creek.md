# Bullrun Creek (Union/Knox/Anderson counties, TN) — Clinch River/Melton Hill tributary
## Evidence-repair research log — 2026-09-24
Ledger state at start: unresolved — no trout program, no survey, no dated record.

Name variants used throughout: **Bullrun Creek** (GNIS spelling; USGS gage 03535000 "BULLRUN CREEK NEAR HALLS CROSSROADS, TN"; TDEC AU labels "Bullrun Creek") and **Bull Run Creek** (TDEC 2005 plan text, TVA "Bull Run Creek embayment"). Disambiguated AWAY from: Bull Run (Virginia battleways), Bull Run Creek McMinn Co. TN (INHS stoneflies at 35.30453,-84.64659 = different creek), Bull Run Creek Scott Co. VA (Clinch River trib at CRM 246.2, in mussel reassessment literature), Bull Run Fossil Plant (the plant itself — used as data opportunity), Bull Run Creek KY. TVA's plant is on the Clinch River/Melton Hill at CRM ~47-48 with the Bullrun Creek embayment ~1-1.5 mi downstream.

- 2023 EA: impounded portion adjacent to BRF (mouth area). ## 7. Recommendation
**warmwater-focus** (with the creek's classification currently **unresolved-leaning-warmwater** for map-classification purposes; not trout, not seasonal-stocked).
Reasoning:
- No trout stocking program (TWRA live layer + 2016 dataset + 2026 schedule all zero), no trout specimen/observation record anywhere (GBIF/iNat/NAS all zero for the creek), and the nearest trout documentation (rainbow trout row in 2003 CRM 45/52 samples; Norris tailwater program; Melton Hill dam-area winter fishery) belongs to Melton Hill Reservoir/the Clinch, a different water per TVA's own reach definitions.
- Warmwater evidence exists (angler forum naming striper/catfish/bass/panfish from Bull Run Creek; TVA/TWRA reservoir-fishery lists covering the embayment convergence; state-listed warmwater minnow (flame chub) flagged as potential occupant; mussel/stonefly fauna consistent with a warm, productive, silty-agricultural stream).
- Cold-water suitability is explicitly marginal (TVA 2006: Norris releases keep Melton Hill "marginally low to support warm-water biota and marginally warm to support cold-water biota"); the creek's own thermal regime is undocumented — this is the key gap. If any trout ever occur in the creek they would be transient strays from the impounded mouth reach, which would make a single historical record the most likely form of evidence; the likely record holder would be TVA (Bullrun Fossil Plant 316(a)/Vital Signs files, station IDs 477313-477323/475152/475232/476049/477322/477674) or TDEC (BULLR station IBI sheets, ARAP/305(b) files) — neither publishes creek fish data online.
- Secondary gap: WQP/TDECWR_WQX (406-blocked here) might add E. coli/tissue stations and dates, but no fish.
- If the map requires a dated, type-distinct citation for the creek itself, the best dated anchor is USGS gage 03535000 (station card, Knox Co) plus the TVA 2023 EA's RM 0.0-1.0 use classification and CRM 46.7 mouth; the best dated warmwater catch-documentation remains the undated forum thread (LEAD).
